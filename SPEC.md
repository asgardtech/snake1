# Snake in Browser Project Plan

## Vision / Goals
- Develop a engaging and challenging Snake game that runs entirely within the browser.
- Include randomly placed obstacles that players can collect to increase their snake's length.

## Goals & Non-goals
**Goals:**
- Implement a responsive and intuitive user interface.
- Ensure smooth gameplay with optimal performance in modern browsers.
- Provide clear instructions and feedback to enhance player experience.

**Non-goals:**
- Avoid using any external libraries or frameworks not covered in our initial tech stack.
- Keep the game logic straightforward for maintainability.

## Initial tech stack
- HTML5 Canvas for rendering the game
- JavaScript for game logic and interactivity
- CSS for styling

## First milestone
- **Task:** Set up the basic structure of the game, including the canvas element and initial game state.
- **Expected outcome:** A blank canvas ready for further development.
